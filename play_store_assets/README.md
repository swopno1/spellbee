# Google Play Store Assets — SpellBee

This directory contains all official graphic assets prepared for Google Play Store publication of **SpellBee**, published by **ViveScript Solutions LLC**.

---

## Asset Directory Structure

```text
/play_store_assets/
├── app-icon/
│   └── app-icon.png                  # 512x512 High-Res 32-bit PNG App Icon
├── feature-graphic/
│   └── feature-graphic.png           # 1024x500 Feature Graphic Banner
├── phone/
│   ├── phone-01-home.png             # 1080x1920 Home / Mascot & Welcome
│   ├── phone-02-quiz.png             # 1080x1920 Interactive Quiz & Spoken Audio
│   ├── phone-03-results.png          # 1080x1920 Results & Native Social Sharing
│   └── phone-04-review.png           # 1080x1920 Session Word Review & Tips
├── tablet/
│   ├── tablet-01.png                 # 1200x1920 Tablet Home Layout
│   └── tablet-02.png                 # 1200x1920 Tablet Quiz Layout
└── README.md
```

## Asset Specifications

### 1. App Icon
- **Path:** `play_store_assets/app-icon/app-icon.png`
- **Dimensions:** 512 x 512 px
- **Format:** 32-bit PNG (with alpha)
- **Design:** Barnaby the Honeybee wearing a graduation cap holding a pencil on solid honey gold background (`#FFC72C`).

### 2. Feature Graphic
- **Path:** `play_store_assets/feature-graphic/feature-graphic.png`
- **Dimensions:** 1024 x 500 px
- **Format:** 24-bit PNG
- **Design:** Cheerful banner featuring Barnaby the Bee flying joyfully with honeycombs, letters, and golden honey pots.

### 3. Phone Screenshots
- **Path:** `play_store_assets/phone/`
- **Dimensions:** 1080 x 1920 px (16:9 portrait)
- **Format:** 24-bit PNG
- **Content:** Highlights the core user flows: Home, Audio Pronunciation Quiz, Results & Native Social Sharing, and Word Review.

### 4. Tablet Screenshots
- **Path:** `play_store_assets/tablet/`
- **Dimensions:** 1200 x 1920 px
- **Format:** 24-bit PNG
